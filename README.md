# OGHypeEngine

OGHypeEngine 은 VULKAN을 기본 그래픽 api로 이용하여 제작된 rendering engine이다.   



## 빌드 방법

* 사용중인 환경
  * window
  * cmake 3.20.1
  * visual studio 2019
  * vulkan 1.4.304.1
  * ...
  *
